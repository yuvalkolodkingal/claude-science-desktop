# Building from source

```bash
git clone https://github.com/yuvalkolodkingal/claude-science-desktop
cd claude-science-desktop
npm install
npm run dist          # .deb + .tar.gz into dist/
```

Requirements: Node 20+, Python 3 (the icon is generated by a stdlib-only PNG
writer in `scripts/make-icon.py`).

## Dev loop

```bash
npm run fetch-daemon   # downloads + verifies claude-science into vendor/ (gitignored)
npm start              # runs the wrapper against it
```

`vendor/` is never packaged or committed — it exists so you can iterate without
the app downloading the daemon into its user-data directory.

## Other targets

| Target | Needs |
| --- | --- |
| `.rpm` | `rpmbuild` (`sudo apt install rpm`) |
| pacman | fpm's pacman support |

```bash
npx electron-builder --linux deb rpm pacman tar.gz
```

## Releasing

`.github/workflows/release.yml` runs on a `v*` tag: it builds Linux packages
(with `rpm` and `libarchive-tools` installed), then generates `SHA256SUMS` and
attaches everything to the release.

```bash
npm version patch      # or edit package.json
git push && git push --tags
```

Asset filenames deliberately carry **no version**, so
`releases/latest/download/<asset>` stays a permanent link and the install scripts
never need the rate-limited GitHub API.
